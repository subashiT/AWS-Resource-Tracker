# AWS-Resource-Tracker
AWS Resource Tracker

Overview

AWS Resource Tracker is a shell script tool designed to monitor and manage AWS resources (EC2, S3, Lambda, IAM) using AWS CLI. It helps DevOps teams track resource usage, identify idle resources, and optimize costs by generating automated daily reports.

Features





Lists EC2 instances, S3 buckets, Lambda functions, and IAM users.



Identifies unused resources to prevent unnecessary costs.



Automates reporting with cron jobs for daily insights.



Simple, lightweight, and customizable for AWS environments.
